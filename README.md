# E-Portfolio | นครินทร์ หอยสังข์

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (Electronic Portfolio) ของ **นายนครินทร์ หอยสังข์** จัดทำขึ้นเพื่อรวบรวมและนำเสนอข้อมูลส่วนตัว ความสามารถ ทักษะ ผลงาน และกิจกรรมต่าง ๆ เพื่อแสดงถึงความรู้ ความสามารถ และการพัฒนาตนเอง

## 👨‍💻 ผู้จัดทำ
- **ชื่อ:** นายนครินทร์ หอยสังข์
- **ชื่อภาษาอังกฤษ:** Nakharin Hoisang
- **ความสามารถเด่น:** การพูดคุยและสื่อสารภาษาอังกฤษ

## 🌐 เกี่ยวกับโปรเจกต์

E-Portfolio เป็นเว็บไซต์ที่พัฒนาด้วย HTML, CSS และ JavaScript โดยออกแบบให้มีรูปแบบทันสมัย ใช้งานง่าย และรองรับการแสดงผลทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ

เว็บไซต์ใช้ธีมสีม่วงและสีขาว เพื่อให้มีความสวยงาม เรียบง่าย และดูเป็นมืออาชีพ พร้อมใช้ฟอนต์ Prompt ที่รองรับภาษาไทย

## 📌 ส่วนประกอบของเว็บไซต์

เว็บไซต์แบ่งออกเป็น 4 ส่วนหลัก ได้แก่

### 1. หน้าแรก (Home)
นำเสนอชื่อผู้จัดทำ พร้อมข้อความต้อนรับและปุ่มเชื่อมโยงไปยังส่วนต่าง ๆ ของเว็บไซต์

### 2. แนะนำตัว (About Me)
นำเสนอข้อมูลส่วนตัว ความสนใจ และความสามารถ โดยเน้นทักษะการพูดคุยและสื่อสารภาษาอังกฤษ พร้อมกราฟแสดงระดับความสามารถ

### 3. ผลงาน (Portfolio)
รวบรวมผลงานและโปรเจกต์ที่ได้พัฒนาขึ้น พร้อมปุ่มเชื่อมโยงไปยัง GitHub เพื่อให้ผู้เข้าชมสามารถดูรายละเอียดผลงานและโค้ดได้

### 4. กิจกรรม (Activities)
นำเสนอกิจกรรมและประสบการณ์ต่าง ๆ ที่เกี่ยวข้องกับการเรียนรู้ การพัฒนาทักษะภาษาอังกฤษ และการใช้เทคโนโลยี

## 🛠️ เทคโนโลยีที่ใช้

- **HTML5** ใช้สร้างโครงสร้างเว็บไซต์
- **CSS3** ใช้ออกแบบรูปแบบ สีสัน และการจัดวางองค์ประกอบ
- **JavaScript** ใช้เพิ่มลูกเล่นและการโต้ตอบภายในเว็บไซต์
- **Google Fonts (Prompt)** ใช้แสดงผลตัวอักษรภาษาไทย

## ✨ จุดเด่นของเว็บไซต์

- ออกแบบด้วยธีมสีม่วงและสีขาว
- รองรับภาษาไทย
- รองรับการแสดงผลบนอุปกรณ์หลายขนาด
- มีเมนูนำทางไปยังแต่ละส่วน
- มีกราฟแสดงระดับความสามารถ
- มีปุ่มเชื่อมโยงไปยัง GitHub
- มีเอฟเฟกต์แสดงเนื้อหาเมื่อเลื่อนหน้าจอ

## 🎯 วัตถุประสงค์ของการจัดทำ

1. เพื่อรวบรวมประวัติส่วนตัวและข้อมูลความสามารถ
2. เพื่อเผยแพร่ผลงานและกิจกรรมในรูปแบบออนไลน์
3. เพื่อฝึกฝนทักษะการพัฒนาเว็บไซต์ด้วย HTML, CSS และ JavaScript
4. เพื่อแสดงความสามารถในการสื่อสารภาษาอังกฤษ
5. เพื่อพัฒนาทักษะด้านเทคโนโลยีและการนำเสนอข้อมูล
